# Bausteine Runde 37

Je Aufgabe (`hilfe_text`, `webseite`, `bilder`) eine Datei `docs/r37/<id>.md` mit den Abschnitten „CHANGELOG“,
„Backlog/Offen“, „SKILLS“ und „Nutzerfragen“. Kein Entwickler fasst CHANGELOG, Backlog, SKILLS, HANDOFF, Fahrplan
oder README.md an; der Integrator setzt die Bausteine am Ende der Runde ein und löscht diesen Ordner.
