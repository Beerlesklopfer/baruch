Register

Registereinträge sind Marken im Text, direkt hinter dem Wort; das Bibelstellenregister entsteht von selbst aus den erkannten Bibelstellen. Welche Register das Buch am Ende bekommt, regelt Einstellungen → Werk → Satz. Eine Marke setzen oder entfernen ergibt eine neue Fassung des Abschnitts; Assistenten schlagen Einträge nur vor.
