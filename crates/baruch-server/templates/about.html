Neue Versionen

Baruch fragt nie von sich aus im Netz nach neuen Versionen. Wer nachsehen will, öffnet selbst die Release-Seite dieser Version ({{ release_url }}) – erst der Klick ruft sie im Browser auf. Aktualisiert wird von Hand mit einem neuen Paket von dort; nur wer Baruch unter Debian oder Ubuntu über das APT-Repository bezieht, bekommt neue Versionen mit sudo apt upgrade.
