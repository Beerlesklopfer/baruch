Konten werden nie gelöscht, nur gesperrt: Die Herkunft (@lektorat:…) bleibt vergeben, damit alte Vorschläge, Beiträge und Befunde eindeutig bleiben. Das letzte aktive Autor-Konto lässt sich nicht sperren.

Lektor anlegen

Ein neues Konto ist immer ein Lektor und sieht zunächst kein Werk. Freigegeben wird je Werk auf der Seite „Mitwirkende“{% if work %}: Mitwirkende dieses Werks{% else %} (Reiter Buch → Mitwirkende){% endif %}. Das Passwort gibst du dem Lektor selbst weiter; er kann es unter „Mein Konto“ ändern.

Am eigenen Rechner ohne Anmeldung

Stand: {% if local_open %}eingeschaltet – am eigenen Rechner gelten Autorrechte ohne Passwort{% else %}ausgeschaltet – auch am eigenen Rechner ist eine Anmeldung nötig (Vorgabe){% endif %}

Vorsicht mit einem Proxy auf demselben Rechner: Ein Reverse-Proxy verbindet sich ebenfalls über 127.0.0.1. Baruch erkennt ihn an seinem Rechnernamen (--allow-host) und an den Kopfzeilen Forwarded, X-Forwarded-*, X-Real-IP und Via. Ein Proxy, der den Host umschreibt und keine dieser Kopfzeilen setzt, sähe aus wie der eigene Rechner – dann hätte jeder Besucher Autorrechte. Nur einschalten, wenn kein solcher Proxy vor Baruch steht.
