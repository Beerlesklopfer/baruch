Tokens für andere Rechner

Mit einem Token nimmt /mcp Anfragen von jedem Rechner an (Authorization: Bearer <Token>); alle anderen Seiten bleiben dem eigenen Rechner vorbehalten. Dafür muss Baruch auf einer Adresse im Netz lauschen (--listen 192.168.…:8765), und der andere Rechner spricht ihn über die IP-Adresse an, nicht über einen Namen. Achtung: Baruch spricht nur HTTP ohne Verschlüsselung – Token und Texte gehen im Klartext durchs Netz. Nur im eigenen, vertrauenswürdigen Netz verwenden. Verschlüsselt und unter einem Rechnernamen geht es nur über einen Reverse-Proxy mit TLS (--allow-host, docs/Betrieb.md).
