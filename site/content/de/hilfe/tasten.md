Alle Tasten gelten nur mit JavaScript; ohne JavaScript bedient man Baruch über Verweise und Formulare.

**Zum Mac:** Wo Baruch die Taste Strg auswertet, gilt am Mac fast überall auch ⌘ (Befehl); statt Alt gilt ⌥
(Wahl), statt Umschalt ⇧. Die Mac-Spalte ist **aus dem Programm abgeleitet, am Mac aber nicht ausprobiert**. Wo
das Programm am Mac erkennbar anders arbeitet oder eine Taste dort vermutlich nicht ankommt, steht es dabei.
Pos1 und Ende liegen auf Mac-Tastaturen ohne diese Tasten auf Fn+← und Fn+→, Entf auf Fn+Rückschritt.

## Überall {#ueberall}

| Aktion | Windows/Linux | Mac |
|---|---|---|
| Speichern (auf der Arbeitsseite, gleich wo der Cursor steht) | Strg+S | ⌘S |
| Vorige / nächste Fassung zeigen | Alt+← / Alt+→ | ⌥← / ⌥→ |
| Nach einem Sprung an die Ausgangsstelle zurück | Alt+← | ⌥← |
| Einfall festhalten | Alt+E | ⌥E |
| Literatur öffnen und schließen | Alt+L | ungeprüft – ⌥L erzeugt am Mac ein Sonderzeichen, und Baruch wertet hier nur das Zeichen aus; sicher geht **Prüfen → Literatur** |
| Einstellungen öffnen | Alt+, | ungeprüft – aus demselben Grund; sicher geht **Baruch ▾ → Einstellungen** |
| Im Werk suchen | Strg+Umschalt+F | ⌘⇧F |
| Im Werk ersetzen | Strg+Umschalt+H | ⌘⇧H |
| Bereich unter dem Mauszeiger vergrößern oder verkleinern | Strg+Mausrad | am Mac ebenfalls Ctrl+Mausrad (⌘ gilt hier nicht); am Touchpad zwei Finger auseinanderziehen |
| Bereich unter dem Mauszeiger auf 100 % | Strg+0 | ⌘0 |
| Fenster, Menü, Schublade oder Liste schließen | Esc | Esc |

## Menüband {#menueband}

| Aktion | Windows/Linux | Mac |
|---|---|---|
| Menü Baruch ▾ öffnen | ↓ oder Enter | ↓ oder ↩ |
| Im Menü wandern, schließen | ↑ ↓, Esc | ↑ ↓, Esc |
| Von Reiter zu Reiter, von Knopf zu Knopf | ← → | ← → |
| Erster / letzter Reiter oder Knopf | Pos1 / Ende | Fn+← / Fn+→ |
| Vom Reiter in seine Knöpfe | Tab | Tab (⇥) |
| Spaltengrenze verschieben (Grenze mit Tab ansteuern) | ← → | ← → |

## Gliederung {#gliederung}

Die Tasten F2, Entf und die Kontextmenü-Taste wirken nur, wenn die Gliederung den Fokus hat.

| Aktion | Windows/Linux | Mac |
|---|---|---|
| Eintrag umbenennen | F2 | F2 (je nach Einstellung des Mac Fn+F2) |
| Umbenennen bestätigen / abbrechen | Enter / Esc | ↩ / Esc |
| Eintrag löschen (mit Rückfrage) | Entf | ⌦ bzw. Fn+Rückschritt |
| Kontextmenü am Eintrag | Umschalt+F10 oder Kontextmenü-Taste | ⇧F10; eine Kontextmenü-Taste hat der Mac nicht – Rechtsklick oder Knopf ⋯ |
| Eintrag nach oben / unten verschieben | Alt+Umschalt+↑ / ↓ | ⌥⇧↑ / ⌥⇧↓ |
| Eintrag höher / tiefer stufen | Alt+Umschalt+← / → | ⌥⇧← / ⌥⇧→ |

| Einem Querverweis folgen | Strg+Klick | ⌘-Klick |

## Maus {#maus}

Am Mac ist der Rechtsklick auch ein Klick mit zwei Fingern oder Ctrl-Klick.

| Geste | Wo | Wirkung |
|---|---|---|
| Klick | Gliederung | öffnet den Abschnitt |
| Doppelklick | gewählter Eintrag der Gliederung | benennt um |
| Rechtsklick oder Knopf ⋯ | Eintrag der Gliederung | Kontextmenü: neuer Punkt, umstufen, löschen |
| Ziehen und Ablegen | Eintrag der Gliederung | oberes Drittel: davor · Mitte: darunter · unteres Drittel: danach |
| Ziehen | Grenze zwischen den Spalten | ändert die Spaltenbreite |
| Klick | Leiste am Rand (Laptop-Modus) | holt die Spalte als Schublade; ein Klick daneben legt sie weg |
| Klick | gewählter Reiter des Menübands oder ▴ | klappt das Band ein |
| Doppelklick | gelb hinterlegte Stelle im Satzbild | öffnet ihren Quelltext |
| Rechtsklick | markiertes Wort im Text | Glossar und Register |
| Rechtsklick | markierter Text in einer Quelle | Hervorheben, Zitieren, An Persona geben, Ähnliches suchen |
| Klick | Kopfzeile eines Vorschlags | klappt ihn ein und aus |
| Klick / Umschalt-Klick | Versnummer auf der Bibelseite | setzt die Stelle / erweitert sie bis dorthin |
| Klick | Zelle in der Tabelle der Befunde | zeigt genau deren Befunde |
| Strg+Mausrad (Mac: Ctrl+Mausrad) | über einem Bereich | vergrößert nur diesen Bereich |
| Ziehen | Einfall in der Mindmap | umhängen, einordnen, in die Wolke legen |
| Ziehen | freie Fläche der Mindmap | verschiebt den Ausschnitt |
| Ziehen | Rahmen im Umschlag-Editor | verschiebt den Block; Griffe an den Ecken ändern die Breite |
