All keys work only with JavaScript; without JavaScript you use Baruch through links and forms.

**About the Mac:** where Baruch evaluates the Ctrl key, on the Mac ⌘ (Command) almost always works as well;
instead of Alt, ⌥ (Option) applies, instead of Shift ⇧. The Mac column is **derived from the program but not tried
on a Mac**. Where the program recognisably works differently on the Mac or a key probably does not arrive there, it
says so. Home and End are on Fn+← and Fn+→ on Mac keyboards without these keys, Del on Fn+Backspace.

## Everywhere {#ueberall}

| Action | Windows/Linux | Mac |
|---|---|---|
| Save (on the workspace, wherever the cursor is) | Ctrl+S | ⌘S |
| Show previous / next revision | Alt+← / Alt+→ | ⌥← / ⌥→ |
| Back to the starting point after a jump | Alt+← | ⌥← |
| Capture an idea | Alt+E | ⌥E |
| Open and close the literature | Alt+L | unchecked – ⌥L produces a special character on the Mac, and Baruch only evaluates the character here; **Review → Literature** always works |
| Open the settings | Alt+, | unchecked – for the same reason; **Baruch ▾ → Settings** always works |
| Search in the work | Ctrl+Shift+F | ⌘⇧F |
| Replace in the work | Ctrl+Shift+H | ⌘⇧H |
| Zoom the area under the mouse pointer in or out | Ctrl+mouse wheel | on the Mac also Ctrl+mouse wheel (⌘ does not work here); on the touchpad spread two fingers |
| Reset the area under the mouse pointer to 100 % | Ctrl+0 | ⌘0 |
| Close a window, menu, drawer or list | Esc | Esc |

## Ribbon {#menueband}

| Action | Windows/Linux | Mac |
|---|---|---|
| Open the menu Baruch ▾ | ↓ or Enter | ↓ or ↩ |
| Move in the menu, close it | ↑ ↓, Esc | ↑ ↓, Esc |
| From tab to tab, from button to button | ← → | ← → |
| First / last tab or button | Home / End | Fn+← / Fn+→ |
| From the tab into its buttons | Tab | Tab (⇥) |
| Move a column border (reach the border with Tab) | ← → | ← → |

## Outline {#gliederung}

The keys F2, Del and the context menu key work only when the outline has the focus.

| Action | Windows/Linux | Mac |
|---|---|---|
| Rename an entry | F2 | F2 (depending on the setting of the Mac Fn+F2) |
| Confirm / cancel renaming | Enter / Esc | ↩ / Esc |
| Delete an entry (with a question) | Del | ⌦ or Fn+Backspace |
| Context menu at the entry | Shift+F10 or context menu key | ⇧F10; the Mac has no context menu key – right-click or button ⋯ |
| Move an entry up / down | Alt+Shift+↑ / ↓ | ⌥⇧↑ / ⌥⇧↓ |
| Promote / demote an entry | Alt+Shift+← / → | ⌥⇧← / ⌥⇧→ |

## Search and replace in the section {#suchen}

| Action | Windows/Linux | Mac |
|---|---|---|
| Open the search bar | Ctrl+F | ⌘F |
| Open the line "Replace" | Ctrl+H | ⌘H – if the system hides the window with it, Ctrl+H works |
| Next hit | Enter or F3 | ↩ or F3 |
| Previous hit | Shift+Enter or Shift+F3 | ⇧↩ or ⇧F3 |
| Match case, whole word, regular expression | Alt+C, Alt+W, Alt+R | ⌥C, ⌥W, ⌥R |
| Only in the selection | Alt+L | ⌥L |
| Replace the current hit | Ctrl+Shift+1 | ⌘⇧1 |
| Replace all | Ctrl+Alt+Enter | ⌘⌥↩ |
| Close the search bar | Esc | Esc |

## Mouse {#maus}

On the Mac the right-click is also a click with two fingers or Ctrl-click.

| Gesture | Where | Effect |
|---|---|---|
| Click | outline | opens the section |
| Double click | chosen entry of the outline | renames it |
| Right-click or button ⋯ | entry of the outline | context menu: new item, change the level, delete |
| Drag and drop | entry of the outline | upper third: before · middle: below it · lower third: after it |
| Drag | border between the columns | changes the column width |
| Click | bar at the edge (laptop mode) | brings the column as a drawer; a click next to it puts it away |
| Click | chosen tab of the ribbon or ▴ | folds the ribbon |
| Double click | place with a yellow background in the typeset view | opens its source text |
| Right-click | selected word in the text | glossary and index |
| Right-click | selected text in a source | highlight, quote, give to a persona, find similar |
| Click | head line of a proposal | folds and unfolds it |
| Click / Shift-click | verse number on the Bible page | sets the reference / extends it up to there |
| Click | cell in the table of findings | shows exactly its findings |
| Ctrl+mouse wheel (Mac: Ctrl+mouse wheel) | over an area | zooms only this area |
| Drag | idea in the mind map | re-attach, arrange, put into the cloud |
| Drag | free area of the mind map | moves the view |
| Drag | frame in the cover editor | moves the block; handles at the corners change the width |
